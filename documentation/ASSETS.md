# Images et illustrations

Les fichiers de `public/images/` sont servis comme ressources statiques par Vite et copiés dans `dist/` lors du build. Les composants les référencent avec des chemins tels que `/images/community-health-worker-togo.jpg` : aucune connexion à Wikimedia Commons n’est nécessaire pour afficher les images déployées.
